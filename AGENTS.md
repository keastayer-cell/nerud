# Правила проекта

- Интерфейс находится в `web/src`: `pages`, `components`, `data`, `assets`.
- Следовать организации `bg_foot_project`: `web`, `docs`, `ops`, `scripts`, Makefile, README и RELEASE.
- Сначала мобильная вёрстка. Проверять 320/375/390/430 px, планшет и компьютер.
- Название, контакты, ассортимент и тексты редактировать в `web/src/data/company.ts`.
- Данные демонстрационные. Не придумывать отзывы, документы, достижения и реальные адреса.
- Перед публикацией заменить временные данные и снять noindex только после проверки.
- Бэкенд и БД отсутствуют. Не добавлять их без продуктовой необходимости.
- При изменениях поведения обновлять `docs/Руководство-по-продукту.md` и RELEASE.md.
- Проверять сборку, типы и мобильные сценарии. Не выдавать локальный результат за релиз.
