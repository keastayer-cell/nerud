# Нерудные материалы — сайт-визитка

Демонстрационная версия ООО «БУР Строй». Название, адрес, телефон с кодом города и основные
услуги получены от заказчика. Подробный ассортимент, часы и фотографии уточняются. Основа структуры — `bg_foot_project`.

## Стек

Vue 3, Nuxt 4, TypeScript, обычный CSS. Статическая генерация: сервер приложения
и база данных не требуются. Node.js 22.22.3+ (либо поддерживаемый Node 24), npm.

## Запуск

```sh
nvm use
make web-deps
make run-web
```

Если используется Homebrew Node 22:
`export PATH="/opt/homebrew/opt/node@22/bin:$PATH"`.
Адрес разработки выводится в терминале (обычно http://127.0.0.1:3000).

```sh
make typecheck
make build
make test
```

Для браузерных проверок после установки зависимостей:
`cd web && npx playwright install chromium webkit`.

## Структура

- `web/src/pages` — страницы, `components` — компоненты.
- `web/src/data/company.ts` — единый источник бизнес-контента.
- `web/src/assets/styles` — стили, `web/public/images` — локальные изображения.
- `docs` — руководство и запуск; `ops` — конфигурация статического хостинга.
- `scripts` — служебные команды; `.github/workflows` — проверка сборки.

Выход сборки: `web/.output/public`. Репозиторий: https://github.com/keastayer-cell/nerud. CI и управляемая публикация демо описаны в `docs/GitHub-и-демо.md`.
Вся страница оформлена в фирменной коричнево-охристой палитре и локальном Golos Text.
Каталог: четыре вида материала в одном блоке с выбором существующих фракций.
Изображения временные: роль фото первого экрана отделена от образцов каталога.
Источники и условия использования — `docs/Изображения.md`.
Недостающие сведения — `docs/Недостающие-данные.md`.
Браузерные тесты запускаются после сборки; для локального тестового сервера нужен Python 3.
Лицензии шрифтов сохранены в `web/public/fonts`.
Не подключены аналитика, отправка заявок, трекинг и внешние карты.


## Зависимости перед публичным запуском

Закреплены исправленные `simple-git` и `@simple-git/argv-parser` через overrides.
На 10.10.2026 npm audit всё ещё сообщает предупреждения высокого уровня
в транзитивных инструментах сборки (включая braces и node-forge).
Не применять `npm audit fix --force`: он предлагает откат Nuxt на другую major-версию.
Перед публичным запуском повторить аудит и обновить доступные исправления.
В хостинг загружается только `.output/public`, без node_modules и dev-сервера.
