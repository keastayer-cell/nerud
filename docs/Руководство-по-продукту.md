# Руководство по продукту

Версия 0.6.1. Первый экран облегчён. Демо обновляется через GitHub Actions после проверок: https://keastayer-cell.github.io/nerud/ .
Цель: познакомиться с материалом, выбрать вид/фракцию и позвонить для расчёта.

## Использование

Первый экран повторяет композицию согласованного макета: крупный заголовок слева,
доставка и кнопка звонка справа. Ниже четыре направления — песок, щебень, грунт,
спецтехника — с переходами в соответствующие части страницы. На телефоне направления
образуют сетку 2 × 2. Крупный номер в мобильном блоке, полный телефон — также в шапке
компьютерной версии. Строка фактов сообщает о площадке, весах, оплате и адресе.
Знак в шапке — адаптация в SVG по предоставленному референсу; оригинальный файл не встроен.
Каталог начинается с песка и грунта, без неподтверждённых подвидов и фотографий. Далее — один блок щебня: четыре вкладки переключают вид щебня, кнопки — его фракцию.
Гранит: 5–20 / 20–40 / 40–70. Гравий: 5–20. Известняковый и вторичный: 20–40.
Новые, отсутствовавшие в исходных данных фракции не добавлялись. Выбор гранитной
фракции сохраняется при переходе к другим видам. Вкладки управляются также стрелками,
Home/End, фракции — стандартными кнопками Enter/Space.

Раздел доставки объясняет данные для расчёта, проверку подъезда, согласование стоимости,
сроков и разгрузки. Компания описана через предоставленные факты: своя площадка, автовесы, техника и способы оплаты.
FAQ раскрывается нажатием. Контакты показывают телефон, согласование времени и адрес; почта скрыта, пока не предоставлена;
ссылка `mapHref` открывает поиск по адресу в Яндекс Картах, без неподтверждённой геометки.

Мобильная нижняя панель появляется после ухода крупных кнопок звонка с экрана.
Пока видна крупная кнопка в первом экране, доставке или контактах, панель скрыта.
Меню закрывается выбором раздела и Escape. Все ссылки звонка используют `tel:`.

## Данные и изображения

Контент — `web/src/data/company.ts`. Бренд ООО «БУР Строй», адрес и полный номер 8 (831) 2-322-333 предоставлены заказчиком; часы не подтверждены. Ссылки звонка используют tel:+78312322333. Фирменная палитра — коричневый, охра, графит и светлый фон.
Иллюстрации направлений — отдельные прозрачные изображения, созданные imagegen по
макету заказчика: естественные образцы без лотков и погрузчик. Полоса направлений компактная, без номеров и стрелок под названиями. Заголовок на широком экране — около 80 px, 680, с естественными переносами; кнопка звонка — 54 px. Это не фотографии партии, площадки
или машины компании. Подробности и промпты — `Иллюстрации-направлений.md`.
Фотографии каталога — отдельные образцы в `materials`; источники в `Изображения.md`.
Нельзя приписывать временным снимкам происхождение от заказчика.

Vue/Nuxt, статическая генерация; backend, БД, формы отправки, аккаунты и аналитика отсутствуют.
Noindex и запрет индексации сохранены. Перед окончательным запуском подтвердить подробный ассортимент,
фотографии, права и условия поставки. Публичное демо разрешено владельцем.
Недостающие сведения перечислены в `Недостающие-данные.md`.

## Проверка

`npm run typecheck`, `npm run build`, затем `npm run test:e2e` из `web`.
Браузерные тесты проверяют готовую `.output/public` через временный локальный
HTTP-сервер Python 3 на 127.0.0.1:3100. Это инструмент проверки, не backend сайта.
Dev-сервер для просмотра остаётся на 127.0.0.1:3000.
