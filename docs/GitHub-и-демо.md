# Репозиторий и демо для заказчика

Репозиторий: https://github.com/keastayer-cell/nerud. Основная ветка — `main`.
Сайт остаётся статическим Vue/Nuxt, без backend и БД.

## Автоматические проверки

Push в main и pull request запускают установку по lock-файлу, проверку типов,
статическую сборку и браузерные проверки 320/375/390/430/768/1440 px.
В CI проверяется именно проектный путь `/nerud/`, включая фото, шрифт, favicon,
переключение материалов, фракций, навигацию и звонки.
При падении доступны browser-diagnostics. После успешных проверок собирается Pages artifact.

## GitHub Pages

Адрес демо: https://keastayer-cell.github.io/nerud/ .
Публикация включена с согласия владельца 10.10.2026. В настройках Pages выбран источник
GitHub Actions, переменная репозитория `DEMO_PUBLISH_ENABLED=true`.
Обновления main публикуются автоматически только после успешных проверок.
Для приостановки автоматической публикации установить переменную в `false`: это не удаляет
уже опубликованное демо. Для повторной сборки можно запустить workflow вручную.
Настройка находится в `.github/workflows/ci.yml`. Секреты сервера не нужны.

Ссылка Pages общедоступна. Noindex/nofollow и robots.txt сохранены — это не контроль доступа.
Данные и фото пока демонстрационные; список недостающего — `Недостающие-данные.md`.

## Другой хостинг

Для корня домена собирать без NUXT_APP_BASE_URL. Для подкаталога задать его со слешами:
`NUXT_APP_BASE_URL=/nerud/ npm run build`. Публиковать только `web/.output/public`.
Реальные контакты, условия и фотографии согласовать отдельно до финального запуска.
