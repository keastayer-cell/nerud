# ОПОРА — атлас материала

Локальный пилот 0.3.0. Изменены только шапка, первый экран и блок гранитного щебня.

## Решения

- Golos Text с локальной кириллицей; основной текст 16–18 px, мобильный заголовок 40–44 px.
- Палитра: #F2EFE8 / #242622 / #465B4A / #E9B949.
- Десктоп: 40% текста и 60% фотографии; крупная фракция — обозначение материала, не физическая шкала.
- Мобильный порядок: регион, заголовок, пояснение, телефон и кнопка, подсказка, переход к каталогу, фото.
- Один материал = один блок. Выбор фракции меняет фото, описание и размер зерна; кнопки доступны с клавиатуры.
- Марки прочности/морозостойкости не предоставлены; вместо числовых значений предлагается уточнение партии.
- Нижняя панель звонка скрывается при видимой крупной кнопке на первом экране, в доставке и контактах.
- Остальные разделы сохранены: сравнение исходной разметки и стилей показало полное совпадение.
- Vue/Nuxt, статическая генерация, существующие временные контакты и фотографии; публикации нет.

## Проверка

`npm run typecheck`, `npm run build`, `npm run test:e2e`.
Chromium: 320 / 390 / 430 / 768 / 1440 px. WebKit: 375 px.
Проверяются переполнение, загрузка фото, выбор фракций, клавиатура, меню,
телефонные ссылки, отсутствие дубля крупной кнопки и панели, FAQ и ошибки JavaScript.

Скриншоты браузера находятся в `output/atlas-*-hero.png` и `output/atlas-*-catalog.png`.
Кадры каталога сняты отдельно, без наложения закреплённой шапки и нижней панели.
